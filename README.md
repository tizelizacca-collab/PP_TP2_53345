Paradigmas de Programación — Trabajo Práctico 2
Programación Orientada a Objetos en Java

Descripción

Este proyecto corresponde al Trabajo Práctico N.º 2 de Paradigmas de Programación.
El trabajo continúa con el sistema de gestión de eventos universitarios desarrollado en el Trabajo Práctico N.º 1, incorporando nuevos conceptos de Programación Orientada a Objetos en Java correspondientes a la Unidad 2: Organización, reutilización y recursos avanzados en POO.
A lo largo del proyecto se incorporan mecanismos de manejo de excepciones, persistencia de objetos, interfaces, clases anidadas, programación genérica y ejecución concurrente mediante hilos.

Funcionamiento esperado:
Durante la ejecución se muestran diferentes operaciones realizadas por el sistema, incluyendo la creación de estudiantes y eventos, asignación de salas, creación de actividades, inscripciones, manejo de excepciones, persistencia de eventos, emisión de certificados, filtrado de actividades, cálculo de costos y envío concurrente de tickets.

La ejecución debe mostrar tanto situaciones exitosas como casos controlados mediante excepciones y, en el último ejercicio, la interacción entre el hilo principal y el hilo encargado del envío de tickets.
